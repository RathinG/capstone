## Project Overview
This project analyzes Bangalore city traffic data to understand traffic patterns, identify congestion hotspots, and generate useful insights using Exploratory Data Analysis (EDA) and data visualizations. The findings are presented through interactive dashboards and business recommendations to support better traffic management.

## Project Files
- **Python Notebook** – Data cleaning, EDA, and visualization code.
- **README** – Project overview and file descriptions.
- **Project Scope and Outcomes** – Project objectives, methodology, and key findings.
- **Dashboards** – Interactive Streamlit dashboards for traffic analysis.
